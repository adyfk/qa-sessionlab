# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions focused on the work.
Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behaviour privately to the maintainer through
[GitHub's private reporting](https://github.com/adyfk/qa-sessionlab/security/advisories/new) or by contacting
the repository owner. Reports are handled confidentially.
